# Parte III: Pixel-Security-360

## Descripción

En esta parte del parcial se desarrolla la base de datos del proyecto Pixel-Security-360. El objetivo es organizar la información del sistema mediante tablas relacionadas, utilizando SQL para crear la estructura y realizar consultas.

## Contenido del proyecto

En esta sección se incluirán los siguientes puntos:

- Creación de las tablas y sus relaciones.
- Registro de usuarios y autenticación.
- Administración de reportes y pagos.
- Catálogo de pruebas de seguridad.
- Consultas SQL y operaciones CRUD para insertar, consultar, actualizar y eliminar datos.
- Capturas de pantalla que muestran el desarrollo y la ejecución de las consultas.
- Archivo de respaldo de la base de datos.
- Documentación y lecciones aprendidas durante la realización del proyecto.

## Objetivo

El objetivo de esta parte es aplicar los conocimientos aprendidos en la materia de Base de Datos II, utilizando SQL para diseñar, organizar y administrar la información de Pixel-Security-360.

## Conclusión

Con este proyecto se busca poner en práctica la creación de tablas, el manejo de relaciones, las consultas y las operaciones con datos. También permite reforzar los conocimientos sobre bases de datos y comprender su importancia en el desarrollo de un sistema.
