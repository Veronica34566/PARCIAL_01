# PARCIAL_01

## Base de Datos II

Este repositorio contiene el desarrollo de mi parcial de Base de Datos II. En el proyecto trabajé con el diseño de una base de datos, la implementación de tablas y relaciones, consultas SQL y documentación de los procesos realizados.

## Contenido del repositorio

### Parte I: Diagrama Entidad-Relación
En esta carpeta se encuentra el diagrama entidad-relación, donde representé las entidades principales del sistema, sus atributos y las relaciones entre ellas.

Carpeta: `01_Diagrama_ER`

### Parte II: Implementación con Docker
En esta parte utilicé Docker y MariaDB para crear una base de datos relacional. Incluye las tablas, los registros, las operaciones CRUD, las vistas SQL, el respaldo de la base de datos y las capturas de pantalla de las pruebas realizadas.

Carpeta: `02_Docker`

### Parte III: Pixel-Security-360
En esta sección desarrollé la base de datos para el sistema Pixel-Security-360. Incluye los módulos de usuarios, autenticación, reportes, pagos y tipos de pruebas, además de los registros, el archivo SQL, la documentación y las evidencias.

Carpeta: `03_Pixel_Security_360`

## Herramientas utilizadas

- Docker Desktop
- Docker Compose
- MariaDB
- SQL
- CMD de Windows
- Draw.io
- GitHub

## Conclusión

La realización de este parcial me permitió practicar el diseño de bases de datos, la creación de tablas, las relaciones mediante claves primarias y foráneas, las consultas SQL y el uso de Docker. También aprendí la importancia de documentar los procesos, guardar respaldos y organizar los archivos de un proyecto.

Este trabajo me ayudó a reforzar los conocimientos aprendidos en la materia de Base de Datos II.
